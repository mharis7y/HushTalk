## HushTalk

HushTalk is a mobile communication application that combines basic chat functionality with steganography-based hidden communication. The app allows users to exchange messages normally and also conceal sensitive information inside images and videos for discreet sharing.

The primary objective of HushTalk is to provide an alternative communication platform for local communities, particularly in environments where conventional messaging services may be unavailable, restricted. Instead of relying solely on visible text messages or traditional encryption, HushTalk uses steganography techniques to embed secret messages within images and videos, making sensitive communication less detectable.

### Key Features

* User authentication (login and signup)
* One-to-one chat with basic messaging features
* Image steganography for hiding and extracting secret messages
* Video steganography for hiding and extracting secret messages
* Vault to manage previously steganofied images and videos
* Profile management

### Technology Stack

* React Native
* NativeWindCSS
* Firebase Authentication
* Firebase Firestore
* Appwrite Storage
* Native Android modules for media processing and steganography


This project is intended for educational and research purposes.
